# thinkspread/tap

Homebrew formulae for ThinkSpread software.

```bash
brew install thinkspread/tap/tempo9
```

| Formula | What it is |
|---|---|
| `tempo9` | Server-grade LLM inference on Apple Silicon (macOS 26 or later): OpenAI, Anthropic and Ollama compatible APIs on localhost. Source and documentation: [thinkspread/tempo9](https://github.com/thinkspread/tempo9). |

The `tempo9` binary contains the Tempo9 engine, licensed under the Tempo9
Engine License (installed with it, and in the tempo9 repository); the rest
of the program is Apache-2.0.
